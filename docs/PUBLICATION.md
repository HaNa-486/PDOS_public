# Public source snapshot

Prepared for public-source inspection on 2026-10-27 (Asia/Taipei).

## Included

- Product Development Operating System (PDOS) `0.4.0-alpha.1` Skill, supporting scripts, references, assets and project templates.
- Standalone installers, tests, synthetic eval cases/fixtures, expected outcomes and grading logic.
- MIT License, usage instructions, contribution guidance and an engineering portfolio walkthrough.

Product code is carried over unchanged from the maintainer's existing v0.4 alpha source at the time of this export. Public-facing documentation and ignore rules are revised for this distribution; this is not a new functional version.

## Intentionally excluded

- The original repository's Git database, ancestry, reflogs and backup bundles.
- Root project-administration state, internal reviews, agent run ledgers and private/local notes.
- Generated eval captures, caches, credentials, personal machine paths and release archives.
- PDOS Autopilot, which is a separate product.

This repository starts with a new root commit using the maintainer's GitHub noreply identity. It is not a fork or mirror of the original repository. Only explicitly reviewed public files are committed and pushed; there is no automatic synchronization from the private workspace.

The original repository remains separate. Publishing this clean snapshot does not remove old objects from the original repository or from anyone else's copies.

## Evidence boundary

This is an open-source alpha / portfolio publication, not a production-qualified release. Read [VALIDATION.md](../VALIDATION.md) for executed checks, historical versus current evidence, and known gaps. No live-model benchmark advantage, customer adoption, or productivity improvement is claimed.
